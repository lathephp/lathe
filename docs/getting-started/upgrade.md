# Upgrade guide

This page is generated from the [changelog](changelog.md). Its API changes are the entries marked `[api]`, which change the public API: the classes and methods in the API snapshot, the artisan commands, the config keys, the route names and the JSON contract. Its behaviour changes are the other entries under Changed, which change what the panel does for your users.

These changes happen between 1.0.0-beta.4 and 1.0.0-beta.5. Check each API change against your code before you update, and tell your users about the behaviour changes.

## From 1.0.0-beta.4 to 1.0.0-beta.5

### API changes

- Each filter in the index payload's `filters.available` carries `token`, its key in the filter bar, and `kind`, the value that key takes: `select`, `multiple`, `range`, `date`, `boolean`, `relation` (a remote picker) or `text`. The token is the filter's `key()`, except that a `filterable()` field's filter goes by its label in snake case (`total` for Total) unless that clashes with another filter's key.
- Each saved tab in the index payload's `tabs.saved` carries its search as `q`, and `filters.labels` names the remote values of the saved view `?saved_tab=` opens, so the filter bar draws an open saved view's filters and search as its chips and text; changing one leaves the view and writes every chip to the URL.
- A select opts into a status meter with `meter(except: [...])`. The payload carries the tick values as `meter`, and a meter with fewer than 2 or more than 5 ticks throws a `LogicException` naming the field when `fields()` builds. The workbench's order status leaves Cancelled out of the ticks:

  ```php
  Field::select('Status')
      ->options(['pending' => 'Pending', 'paid' => 'Paid', 'shipped' => 'Shipped', 'cancelled' => 'Cancelled'])
      ->meter(except: ['cancelled']);
  ```
- `->board('<field>')` on a Resource's definition shows its list as a Board too, one column per option of that index field in declared order, plus a No value column when the field is nullable. The field must be an inline select with at most 12 inline options; anything else throws a `LogicException` naming the field when the Resource boots, and a subclass that drops the field calls `->board(null)`. The index payload carries `table.board`, `{field, noValue}`, or `null` on a lens, without a board, or when the user cannot see the field.

  ```php
  return $definition
      ->model(\App\Models\Order::class)
      ->board('status');
  ```
- A list with a board opens in the layout its URL names, `?layout=board` or `?layout=table`, else in the one the user chose last on that Resource, else as the table. `PUT .../resources/{resource}/layout` with `{layout}` saves the choice per user (404 for a Resource without a board), and the index sends the layout it opened in as `table.layout`, always `table` on a lens or without a board.
- `GET .../resources/{resource}/board?column=<option>&page=<n>` returns `{rows, hasMore}`: one page of 25 cards of a Board column, each row shaped as in `table.rows`, in the list's sort. `&offset=<n>` in place of `page` starts at that card, which the Board's Show more sends so a card moved out of the column skips none. An empty `column` is the No value column, allowed on a nullable field; an unknown column, a bad page or offset, or one at the count cap or past it is 422, and a Resource without a board is 404. `GET .../board/counts` returns `{columns: [{value, count}]}`, one capped count per column in option order with `null` last on a nullable field. Both read the index's own query keys (`filter`, `q`, `tab`, `saved_tab`, `sort`).
- `GET .../{id}/preview` serves the preview panel. With an empty `fieldsForPreview()` it returns the record's detail fields without its relation lists (a BelongsTo or MorphTo name stays), so every Resource has a preview; `showOnPreview()` no longer narrows it, a field marked `showOnPreview()` or `onlyOnPreview()` joins it, and `hideFromPreview()` still drops a field. The reply adds the record's `abilities` and its detail `actions`. Each user's panel is open or closed per Resource: `PUT .../resources/{resource}/preview-panel` with `{open}` saves it, and the index sends it as `table.previewOpen`. The preview modal and the row's Preview button (the English string `Preview :title`) are gone, with the index's `resource.preview` flag: Space opens the panel on the cell cursor's row, `clickAction('preview')` opens it on the clicked row, and `TagField::withPreview()` opens it over the page.
- An app with no colours of its own opens in the new identity: steel neutrals, the layout blue primary (`#2e47e0` in light, `#8796ff` in dark), the teal `info`, and an 8 px panel radius. The 56 token names keep their names and meaning; only their default values change. An app that sets any colour keeps its look. To keep copper, run `php artisan lathe:preset copper`.
- `theme.radius` defaults to `0.5rem` (was `0.625rem`). A published `config/lathe.php` keeps the radius it lists; set it to `0.5rem` for the new corners.
- The bundled typeface is Archivo, with its width and weight axes in the latin and latin-ext subsets, in place of Inter Variable. `theme.font` set to `null` uses it; page and record titles and widget values use its 122% width.
- Changed English strings since 1.0.0-beta.4, for an app that translates the panel; move each override to its new key: `Tabs` reads `Views` (the views rail and the Views menu). `Filter`, `:count :resource` and `Show :count :resource` are gone with the index's Filter popover; the filter bar of a Resource that cannot search is named `Filter :resource`. `Edit :field` is gone now that a cell opens its control from the keyboard, and `Preview :title` with the row's Preview button. New strings to translate: `:filter has no option :value`, `:filter takes a date as YYYY-MM-DD, >date, <date or a..b`, `:filter takes a number, >n, <n or a..b`, `:filter takes any text`, `:filter takes one value`, `:filter needs a value`, `:filter takes yes or no`, `Arrow keys`, `Board`, `Change undone`, `Clear the selection`, `Double-click`, `Edit a cell`, `Extend the selection`, `Go to the row's first or last cell`, `Keyboard shortcuts`, `Layout`, `Move 25 rows`, `Move the cell cursor`, `Move :title`, `Move to`, `No :filter matches :value`, `No :resource`, `No filter named :key`, `No value`, `Open full page`, `Open the row, on a cell that cannot be edited`, `Preview the row beside the list`, `record`, `Save and move right`, `Select`, `Select all matching`, `Select the page`, `Select the row`, `Show more`, `Show this sheet`, `Space`, `Table`, `This :resource was deleted.`, `Trashed takes with or only`, `Undo the last cell edit`, `You may not view this :resource.`.
- Every Resource list, lens and relation table is a grid with one tab stop and a cell cursor: a click on a cell moves the cursor and no longer opens the row; the arrows, Home, End, Page Up and Page Down move it. `clickAction` now names what Enter on a cell that cannot be edited, or a click on the title cell, does. An inline cell shows its value until Enter, F2 or a double-click opens its control, so the English string `Edit :field` is gone; Tab saves and moves right, Escape cancels, a refused value stays open with the server's message, and a stale save opens the conflict dialog. Ctrl/Cmd+Z, or the toast's Undo, undoes the last cell edit made in the tab; running an action empties that history. Undo covers cell edits and Board moves only: an action, a delete or a form save cannot be undone. X, Shift+Up/Down and Shift+click select rows, Escape clears them, and `?` on a list, or Keyboard shortcuts in the user menu, lists the keys. The row abilities gain `inlineEdit` when a column edits inline, relation rows carry `updatedAt`, and Load more stops at 100 rows, where a pager takes over.

### Behaviour changes

- A resource index lists its views in a 220 px rail at the card's left, in place of the tab band: the developer tabs, then the user's saved views (Save view, rename, delete, and reorder by dragging or with Alt+Up/Down), then the lenses. Tabs and saved views keep their deferred, capped counts; lenses show none. Below 1100 px, or while the preview panel sits beside the card, the rail folds into a Views menu at the start of the toolbar, which opens the same list. Saved tabs carry over as views unchanged.
- A resource index and its lenses filter from one bar above the table, in place of the search box, the Filter button with its popover, and the chip row under the toolbar. Type `status:pending,paid`, `total:>1500`, `total:10..50` or `customer:"Ann Taylor"` and press Enter: each token becomes a chip that writes the real `filter[...]` keys (`trashed:with` or `trashed:only` the `trashed` key), plain words search as `q` did, and a token that cannot apply shows as a red chip with its reason, such as "No filter named statuz", without changing the rows. A chip change sends one visit 300 ms after the last; Backspace in the empty input removes the last chip, Left arrow reaches the chips and `/` focuses the bar. A reload or a shared link draws the same chips from the URL. A click on the bar lists the Resource's filters, and typing the start of one's name or key (`sta`) narrows the list to it; choosing a filter puts its key in the input and lists its values (a relation's from its options search, a range, date or text filter its grammar), and choosing a value adds the chip. Up and Down move through the list, Enter picks the highlighted item and Escape closes it. Relation tables keep their search box and filter panel.
- A Resource with `->board()` lists as a Board too: a Table/Board switch beside the filter bar shows one column per option, each headed by the option's meter or badge and its count capped at 10,000+, with 25 cards and Show more; a card shows its phone card's title, badge, value and meta. The Board follows the filter bar, the search and the open view, and stays chosen per user and in the link (`?layout=board`). Drag a card to another column, press Shift+Left or Shift+Right on it, or use its Move to menu: the field saves as its inline edit does, both counts change, a refused move goes back with the reason, and Ctrl/Cmd+Z or the toast's Undo takes it back. The arrows move between cards, Space or a click opens the preview panel, and the Board selects nothing. A phone and a lens show no Board. New English strings: `Board`, `Table`, `Layout`, `No :resource`, `No value`, `Show more`, `Move :title` and `Move to`.
- Table rows are 40 px tall at the comfortable density (was 48 px), and the nova style's default buttons, inputs and selects are 32 px (was 34 px).

## What you see
